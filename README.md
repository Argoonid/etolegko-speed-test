# Замер скорости скачивания (CLI)

Консольная утилита на Python для оценки скорости интернет-соединения. Выполняет 10 последовательных HTTP/HTTPS-запросов к указанному URL, полностью вычитывает каждый ответ и выводит статистику по времени, объёму данных и итоговой скорости.

## Требования

- Python 3.10+ (внешние зависимости не требуются, используется только стандартная библиотека).

## Запуск

Базовый запуск (10 последовательных запросов):

```bash
python measure_speed.py "[https://speed.cloudflare.com/__down?bytes=5000000](https://speed.cloudflare.com/__down?bytes=5000000)"
```

Запуск с заданным числом запросов и тайм-аутом:

```bash
python measure_speed.py "[https://speed.cloudflare.com/__down?bytes=5000000](https://speed.cloudflare.com/__down?bytes=5000000)" -n 10 -t 20
```

Вывод отчёта в формате JSON (без строк прогресса в `stdout`):

```bash
python measure_speed.py "[https://speed.cloudflare.com/__down?bytes=5000000](https://speed.cloudflare.com/__down?bytes=5000000)" --json
```

Запуск автотестов (используют локальный `ThreadingHTTPServer`, доступ в интернет не требуется):

```bash
python -m unittest discover -v
```

## Параметры CLI

| Аргумент | По умолчанию | Описание |
| --- | --- | --- |
| `url` | — | HTTP/HTTPS-адрес ресурса для скачивания |
| `-n`, `--requests` | `10` | Количество последовательных запросов |
| `-t`, `--timeout` | `30.0` | Тайм-аут одного запроса в секундах |
| `--json` | `False` | Вывести итоговую статистику и пошаговые замеры в JSON |

## Пример вывода

```text
[1/10] 5.00 MB за 1.822 с (TTFB 255 мс, 21.96 Mbps)
...
[10/10] 5.00 MB за 0.926 с (TTFB 290 мс, 43.17 Mbps)
----------------------------------------------------
Запросов выполнено: 10
Скачано всего:      50.00 MB (50,000,000 B)
Общее время:        10.616 с
Время запроса:      avg 1.062 с | med 0.941 с | min 0.820 с | max 1.822 с
Средний TTFB:       281 мс
Скорость:           37.68 Mbps (4.71 MB/s)
```

## Единицы измерения и методика расчёта

- **Mbps (Мбит/с)** — основная единица сетевой скорости в десятичной системе СИ: `1 Mbps = 1 000 000 бит/с`.
- **MB/s (МБ/с)** — дополнительная единица для оценки загрузки файлов: `1 MB = 1 000 000 байт` (`1 MB/s = 8 Mbps`).
- **Среднее время запроса:** `total_time / requests_count`. Дополнительно считаются медиана (`med`), `min`, `max` и средний `TTFB` — так сразу видны выбросы на холодном старте.
- **Итоговая скорость:** `total_bytes / total_time` — взвешенная скорость по суммарному полному времени всех запросов.

### Детали реализации

- **Память:** ответ вычитывается потоково в единый переиспользуемый буфер `bytearray` размером 256 КБ через `readinto()` без аллокаций на каждый чанк.
- **Целостность данных:** при наличии заголовка `Content-Length` проверяется фактический объём прочитанных байт — оборванное соединение (`IncompleteDownloadError`) или пустое тело ответа (`EmptyResponseError`) не попадают в статистику.
- **Точность замера:** используется монотонный таймер `time.perf_counter()`. Заголовки `Cache-Control: no-cache`, `Pragma: no-cache` и `Accept-Encoding: identity` снижают влияние кэширования и прозрачного сжатия.
- **Ограничение транспорта:** стандартный `urllib` открывает новое TCP/TLS-соединение на каждый запрос; накладные расходы на установку соединения и ответ сервера отражаются в метрике `TTFB`.
